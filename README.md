# dsh-notify-overlay

<img src="icon.svg" width="64" height="64" alt="">

DeepSeek Harness 的置顶通知浮窗。

审批、提问、出错、轮次完成时，在屏幕右下角弹一张自绘卡片。会阻塞对话的提醒收进一个可拖动的小球，点开就是待处理列表，点任意一条跳回对应会话并把 DSH 提到前台。

关掉浮窗开关则改用系统通知，macOS / Linux 靠这条路可用。

## 安装

```
dsh plugin --profile desktop add github:RicardoYan/dsh-notify-overlay#v0.1.2
```

装完重启 DSH。卸载把 `add` 换成 `remove`。

## 配置

设置 → 插件 → 通知浮窗。改完立即生效，不用重启。

| 项 | 默认 | 说明 |
|---|---|---|
| 用浮窗提醒 | 开 | 关掉改用系统通知 |
| 审批 / 提问 / 出错 | 开 | 会一直留着，直到你处理完 |
| 轮次完成 | 开 | 弹一下就走 |
| 子代理完成 / 会话结束 | 关 | 弹一下就走 |
| 卡片停留时长 | 6000 | 3–8 秒 |
| 界面缩放 | 1 | 0.6–1.8 倍 |
| 提示音 | 开 | 仅浮窗模式 |
| 免打扰时段 | 关 | 支持跨午夜；审批和提问不受影响 |

## 两种投递方式

浮窗是 Windows 独占的（WPF 进程），macOS / Linux 只能用系统通知。开关照字面执行——非 Windows 上把开关打开就什么都不发。

| | 浮窗 | 系统通知 |
|---|---|---|
| 看到有提醒 | ✅ | ✅ |
| 点击跳回会话 | ✅ | ❌ |
| 待处理列表 | ✅ | ❌ |
| macOS / Linux | ❌ | ✅ |

**系统通知只负责提醒，点击没有反应。** 这是取舍：让点击有用要走渲染进程，而 DSH 窗口隐藏时会把定时器节流到约一分钟一次，正好是通知唯一有意义的场景。

## 已知限制

- 浮窗只有 Windows，需要 .NET Framework 4.8（Win10 1803+ 自带）
- macOS / Linux 的系统通知未在真机验证
- 小球位置只存内存，DSH 重启后回右下角
- 系统通知模式下提示音不生效
